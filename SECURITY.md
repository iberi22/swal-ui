# Security Policy — SouthWest AI Labs (SWAL)

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `@swal/ui` or any SWAL ecosystem repository, please do not disclose it publicly.

1. Email security reports to `security@southwestailabs.org` or open a confidential issue via Maloca support.
2. Provide details including steps to reproduce, affected components, and potential impact.
3. The SWAL team will respond within 48 hours and coordinate a patch and security release.
