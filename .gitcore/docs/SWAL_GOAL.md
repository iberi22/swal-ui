# SWAL Goal — SouthWest AI Labs Ecosystem

## Vision & Objective
SouthWest AI Labs (SWAL) is an open ecosystem for sovereign AI agents, decentralized edge nodes, and autonomous developer tools.

## Key Principles
1. **Sovereignty & Open Source:** Powered by AGPL-3.0 licensing and open protocol standards.
2. **Pro Membership via Active Nodes:** Active SWAL node participation unlocks Pro capabilities — no paywalls or traditional subscription processors like Stripe.
3. **Decentralized Memory & Mesh:** Xavier HTTP/MCP memory layer (`app/{appId}/instance/{instanceId}`) and WebRTC edge-mesh data plane (`swal/{appId}/{instanceId}`).
4. **Token Economics:** $SWAL ownership and staking yields govern ecosystem participation.
5. **Unified Design System:** Shared UI components (`@swal/ui`) built on Svelte 5 runes and Astro Jamstack architectures.
