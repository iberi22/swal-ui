# @swal/ui — SWAL Design System

Componentes reutilizables para todas las apps del ecosistema SWAL.

## Stack
- **shadcn/ui** — Base de componentes (Radix UI + Tailwind)
- **Tailwind CSS v4** — Utility-first CSS
- **Motion One** — Animaciones 120Hz (opcional)
- **Svelte transitions** — Transiciones nativas GPU

## Tema
Dark/Gris minimalista. Sin animaciones flash. Sombras sutiles.
Colores de acento configurables por ambiente (azul por defecto).
